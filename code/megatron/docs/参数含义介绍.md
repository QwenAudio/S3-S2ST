## megatron-lm常见参数

#### 训练参数

- micro-batch-size：每个device的局部批次大小，默认为None。
- global-batch-size：总批次大小，等价于micro-batch-size\*数据并行大小\*梯度累加步数。默认为None。
- recompute-activations：重新计算激活，降低显存，默认为False（等价于`--recompute-granularity selective`）。
- recompute-granularity：重新计算激活的粒度，可选项为'full', 'selective'。其中full代表重新计算整个transformer layer，selective代表只计算transformer layer中的核心注意力部分。通常'selective'是推荐的（当recompute-activations设置为True时，'selective'为默认）。
- use-cpu-initialization：在cpu上初始化权重，默认为False。
- train-iters：训练的总迭代次数，默认为None。
- train-samples：训练的总样本数，默认为None。train-iters和train-samples必须提供一个。
- log-interval：log的时间间隔（单位：iters），默认为100。
- tensorboard-dir：tensorboard日志写入的目录。默认None。
- no-bias-swiglu-fusion（bias_swiglu_fusion）：默认bias_swiglu_fusion为True，指定`no-bias-swiglu-fusion`，bias_swiglu_fusion设置为False，用于禁止bias和swiglu融合。
- no-rope-fusion（apply_rope_fusion）：默认apply_rope_fusion为True。该参数用于禁止rope融合。
- no-gradient-accumulation-fusion（gradient_accumulation_fusion）：默认gradient_accumulation_fusion为True。该参数用于禁用梯度累加融合。
- cross-entropy-loss-fusion：启动交叉熵损失计算融合。默认为False。
- use-flash-attn：使用 FlashAttention 注意力机制实现，默认为False。
- optimizer：优化器类型，可选为adam、sgd。默认为adam。
- dataloader-type：默认为single，可选为'single', 'cyclic', 'external'。
- manual-gc：禁用默认垃圾回收器，手动触发垃圾回收。默认为False。
- manual-gc-interval：触发垃圾回收的间隔。默认为0。
- use-mcore-models：使用 megatron-core中的模型实现。


#### 学习率参数

- lr：(float) 初始学习率，根据学习率预热策略和衰减策略决定每个迭代的学习率，默认为None。
- lr-decay-style：学习率衰减策略，默认为'linear'。通常设置为'cosine', 'linear', 'constant'。
- lr-decay-iters：(int) 学习率衰减的迭代次数。默认为None，则设置为`--train-iters`。
- lr-decay-samples：(int) 学习率衰减的样本数量。默认为None，设置为`--train-samples。`
- lr-warmup-iters：(int) 线性学习率warmup的迭代次数，默认为0。
- lr-warmup-samples：(int) 线性学习率warmup的样本数量。默认为0。
- min-lr：学习率的最小值，将低于改阈值的学习率裁剪掉，默认为0。


#### 正则化参数

- attention-dropout：默认为0.01。
- hidden-dropout：默认为0.01。
- weight-decay：默认为0.01。
- clip-grad：l2梯度裁剪，默认为1.0。
- adam-beta1：默认0.9。
- adam-beta2：默认0.999。
- adam-eps：默认1e-08。


#### checkpoint参数

- save：checkpoint的输出目录，默认None。
- save-interval：checkpoint保存的间隔（steps），默认None。
- no-save-optim：不保存optimizer，默认为False。
- no-save-rng：不保存rng，默认为False。
- load：加载的checkpoint目录，默认None。
- no-load-optim：不载入optimizer，默认为False。
- no-load-rng：不载入rng，默认为False。
- finetune：将模型加载并微调。不加载检查点的优化器和随机种子状态，并将迭代数设置为0。
- ckpt-format：checkpoint的格式。可选为'torch', 'torch_dist', 'zarr'。默认为'torch_dist'。
- use-dist-ckpt：`--use-dist-ckpt`等价于`--ckpt-format torch_dist`。
- auto-detect-ckpt-format：自动检测ckpt format为legacy还是distributed格式。默认为False。
- exit-on-missing-checkpoint：如果设置了 '--load'，但找不到检查点，则直接退出，而不是随机初始化。


#### 分布式参数

- distributed-backend：分布式后端，可选为'nccl', 'gloo'。默认为nccl。
- use-distributed-optimizer：使用分布式优化器。默认为False。
- tensor-model-parallel-size：tp数，默认为1。
- pipeline-model-parallel-size：pp数，默认为1。
- sequence-parallel：启动序列并行的优化器。默认为False。
- context-parallel-size：cp数，默认为1。
- tp-comm-overlap：启用张量并行通信与GEMM（通用矩阵乘法）内核的重叠。（降低通信耗时）。默认为False。
- overlap-grad-reduce：启用DDP中grad reduce操作的重叠（降低DP通信耗时）。默认为False。
- overlap-param-gather：启用分布式优化器中参数all-gather的重叠（降低DP通信耗时）。默认为False。
- distributed-timeout-minutes：torch.distributed的timeout时间（单位为分钟），默认为10分钟。


#### 模型结构参数

- num-layers：transformer layers的层数，默认为None。
- hidden-size：transformer hidden size，默认为None。
- ffn-hidden-size：transformer FFN层的hidden size。默认为None，设置为4\*hidden-size。
- num-attention-heads：transformer attention heads的个数，默认为None。
- group-query-attention：使用group-query attention。
- num-query-groups：默认为1。
- max-position-embeddings：位置编码的最大长度，默认为None。
- position-embedding-type：位置编码的类型，可选为'learned_absolute', 'rope', 'relative', 'none'，默认为'learned_absolute'。
- use-rotary-position-embeddings：等价于`--position-embedding-type rope`。
- no-position-embedding：和`use-rotary-position-embeddings`一起使用。
- rotary-base：默认为10000。
- rotary-percent：默认为1.0。
- rotary-seq-len-interpolation-factor：序列长度差值系数，默认为None。
- normalization：可选为'LayerNorm', 'RMSNorm'，默认为LayerNorm。
- norm-epsilon：默认为1e-5。
- swiglu：使用swiglu替代默认的gelu。
- untie-embeddings-and-output-weights：解开embedding和输出权重的绑定，默认为False。
- disable-bias-linear（add_bias_linear）：禁用linear层的bias，默认add_bias_linear设置为True。
- add-qkv-bias：仅在QKV的linear中增加bias，默认为False。
- make-vocab-size-divisible-by：将词表大小填充为可被此值整除。该参数出于计算效率原因被添加。默认为128。


#### 混合精度参数

- fp16：fp16模式。默认为False。
- bf16：bf16模式。默认为False。
- apply-query-key-layer-scaling：将Q * K^T 缩放为 1 / 层数（例如：第`layer_num`层则除以`layer_num`）。这对fp16训练很有帮助。同时将 `attention_softmax_in_fp32` 设置为 True。默认为False。
- attention-softmax-in-fp32：在attention_mask和softmax中使用fp32进行计算。默认为False。
- hysteresis：动态loss scale的滞后值，默认为2。


#### transformer engine参数

- transformer-impl：使用哪种transformer实现，可选项为local和transformer_engine。默认为transformer_engine。

#### moe 参数

- moe-router-pre-softmax：在 MoE 路由过程中，在 softmax 计算之前进行预处理。默认为 `False`。
- moe-shared-expert-overlap：允许共享专家在不同的专家间进行重叠计算，以提高计算效率。默认为 `False`。
- num-experts：MoE（Mixture of Experts）中的专家数量，默认为 None, 即没不用 MoE 模型。
- expert-model-parallel-size：ep 数量，默认为1。
- moe-shared-expert-intermediate-size：共享专家的总 FFN 隐藏层大小。默认为 None, 即没有专家。
- moe-grouped-gemm：当每个 rank 上有多个专家时，在多个流中启动多个本地 GEMM 内核，以提高利用率和性能，并在 TransformerEngine 中使用 GroupedLinear。默认为 `False`。
- moe-router-load-balancing-type：MoE 路由负载均衡策略类型，可选为 'aux_loss', 'sinkhorn', 'none'。默认为 `aux_loss`，即引入辅助损失来优化专家分配的均匀性。"sinkhorn" 对应于 S-BASE 中使用的负载均衡算法，而 "none" 表示不进行负载均衡。
- moe-router-topk：每个 token 可以选择的专家数量，默认为 2。
- moe-aux-loss-coeff：MoE 负载均衡辅助损失系数， 默认为 0.0，推荐值为 0.02， 常用取值为 0.2。
- moe-z-loss-coeff：Z 损失系数，用于稳定路由权重的分布，以防止过度偏向某些专家。默认值为 None, 推荐取值为 1e-3, 常用取值为 0.02。
- moe-token-dispatcher-type：要使用的 token dispatcher类型，默认值为 'allgather'。可选项包括 'allgather'、'alltoall' 和 'alltoall_seq'。
在应用ep 时，推荐使用 'alltoall'。更多信息请参考 core/moe/README 中的文档。
- use-flash-moe：启用 `FlashMoE`。
- use-flashmoe-router：启用 `FlashMoE` 路由，以提高路由计算效率。默认为 `False`。这是一个实验性功能。
- flash-moe-interleaving：交错执行专家计算和专家并行（EP）通信，默认为 `False`。
- num-shared-experts：共享专家的数量，None 表示没有共享专家。
- moe-expert-capacity-factor：每个专家的容量因子，默认为 None, 设置为 None 表示不会丢弃任何 token，用于控制每个专家可以接收的 token 负载。
- moe-drop-across-ep：在专家并行训练中进行跨专家丢弃，以提高训练稳定性。默认为 `False`。


#### 日志参数

- log-params-norm：记录参数的norm。默认为False。
- log-throughput：记录每个GPU的吞吐量。默认为False。
- tensorboard-log-interval：记录到tensorboard的间隔（steps），默认为1。
- tensorboard-queue-size：队列长度（与磁盘IO相关），类似于写入的间隔。默认为1000。
- log-timers-to-tensorboard：记录timers到tensorboard。默认为False。
- log-batch-size-to-tensorboard：记录batch_size到tensorboard。默认为False。
- no-log-learnig-rate-to-tensorboard（log_learning_rate_to_tensorboard）：不记录学习率到tensorboard。log_learning_rate_to_tensorboard默认为True。
- log-validation-ppl-to-tensorboard：将验证困惑度写入tensorboard。默认为False。
- log-memory-to-tensorboard：将内存日志写入tensorboard。默认为False。
- logging-level：日志级别。默认为None。


#### 评估参数

- eval-iters：评估的迭代次数，默认为100。
- eval-interval：评估的间隔（steps），默认为1000。

#### 初始化参数

- seed：python、numpy、pytorch和cuda的随机种子，默认为1234。
- init-method-std：权重初始化的零均值正态分布的标准差，默认为0.02。


#### 数据参数

- data-path：data-path：训练、验证和测试的数据集的权重和前缀列表（若前缀省略，则由数据集长度进行推断）。默认为None。例如`--data-path 1 /path/to/dataset_A 1.5 /path/to/dataset_B`，数字与数据源成对出现，数字表示在实际训练中对应数据源的采样权重（权重会进行归一化处理）。训练过程会构建BlendableDataset，根据权重从不同数据源采样数据构建batch。
- split：训练、验证和测试的分割比例，例如：`--split 95,3,2`。默认为None。
- train-data-path：训练集的权重和前缀列表，默认为None。
- valid-data-path：验证集的权重和前缀列表，默认为None。
- test-data-path：测试集的权重和前缀列表，默认为None。
- seq-length：要处理的最大序列长度，默认为None。
- num-workers：dataloder的workers数量，默认为2。
- eod-mask-loss：掩盖文档结束token的损失。默认为False
- no-create-attention-mask-in-dataloader（create_attention_mask_in_dataloader）：在dataloader中不创建attention mask。默认create_attention_mask_in_dataloader为True。
- data-cache-path：存放缓存索引文件（cached index files）的目录，默认为None。


#### tokenizer参数

- vocab-file：词表路径。
- merge-file：BPE（Byte Pair Encoding）合并文件的路径。


## Qwen-Public额外常见参数

- use-flash-cross-entropy：使用flash_attn提供的cross entropy，比mcore提供版本效率更高。
- inplace-flash-cross-entropy：原地计算cross entropy 减低显存占用。
- dynamic-flash-attn：对packing数据的文档使用额外的attention mask，避免不同文档互相可见。
- reduce-loss-per-iteration：对每个micro batch同步loss改为每个global batch同步一次。
- increase-log-level-interval：定期拉高日志等级，打印具体日志，用于分析耗时。
- use-dynamic-collate：使用动态padding，默认为False。


#### dpo参数

- dpo_weight：控制model和ref_model的偏差，更高的dpo_weight代表model和ref_model的偏差更小（等价于trl中的`beta`）。默认为0.1。
- max_response：query对应几个response，通常设置为2（pairwise：chosen，rejected）。默认为1。
- batch-response：默认为False。使用dpo时设置为True即可。
- ref_load：加载ref_model的checkpoint目录，默认None。


#### qwenvl参数
- qwenvl：默认为False。
- use-mrope：使用mrope。默认为False。
- vision-grad-checkpointing：启用视觉编码器的grad checkpointing。默认为False。
- vision-model-config：视觉模型的config路径。默认为None。
- freeze-vision-nlayers：(int) 冻结视觉模型的前n层。默认为None。
- min-pixels：图像最小像素数，默认是`4 * 28 * 28`。
- max-pixels：图像最大像素数，默认是`16384 * 28 * 28`。

### PretrainData

#### encoder_qwen_15w

用于预先编译预训练数据，生成.bin/.idx文件。

位置参数：inputs：可以传入含jsonl文件的目录或者多个jsonl文件路径（最终将打包输出一组bin/idx数据文件）

- output-prefix：输出文件的前缀，默认为None。最终的bin文件路径为`{output_prefix}_qwen_15w.bin`，idx文件路径为`{output_prefix}_qwen_15w.idx`。
- workers：处理的进程数，默认为32。
- file-match-str：匹配的文件类型，只当`inputs`传入的是目录时生效，默认为None。例如你可以设置为'jsonl'。


### SFTData

#### binarize

用于预先编译SFT数据，训练时直接使用带mask信息的.bin/.idx文件。

位置参数：version_tag：（str）输入数据的version tag。即输入的数据集路径为`{root_dir}/{version_tag}`

- root-dir：输入数据集的root dir。
- mask-prompt：对话中`role`是`system`或`user`的所有轮，设置其mask为0（即不计算损失）（仅mask文本内容，special tokens和role string除外）。
- mask-chatml-role：对话中所有的role string（`system/user/assistant`），设置其mask为0（不含special tokens）。
- seq-len：将超过seq-len的样本进行右裁剪。若经右裁剪的样本mask全为0（即样本的前`seq_len`个token均不参与计算loss），则删除该样本。


**mask逻辑**：（mask-prompt、mask-chatml-role不再进行介绍）

- mask_history：
  - 使用方式：构造每条对话数据时，加入如下部分
  ```json
  {
    "mask_options": {
      "num_last_messages_to_keep": 2,
      "keep_system": false
    }
  }
  ```
  - 效果：
    - 除了最后`num_last_messages_to_keep`条对话（一条对话指一个role的message），其余历史对话均设置mask为0（仅mask文本内容，special tokens和role string除外）。
    - 默认情况下，`keep_system`若留空，则为`false`；若设置为`true`，则保留历史对话中的`role == "system"`部分不进行mask。

- token_level_mask：

  - 使用方式：构造每条对话数据时，用特殊字符串设置需要mask的部分
    ```json
    {
      "messages": [
        {"role": "assistant", "content": "我是阿里云推出的一种<|mask_start|>超大规模<|mask_end|>语言模型，<|mask_start|>我叫通义千问。<|mask_end|>"}
      ]
    }
    ```

  - 效果：所有包含在`<|mask_start|>`和`<|mask_end|>`之间的内容，设置其mask为0（`<|mask_start|>`, `<|mask_end|>`特殊字符会从输出结果中移除）。

  - 注：如果`<|mask_start|>`和`<|mask_end|>`将一个完整的token切开，会抛出错误。最终输出保证去掉特殊mask字符串前后的分词结果一致。
